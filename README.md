# Simple Blockchain

This is a small blockchain I made in Java.
I always heard about blockchains but never really understood how they work, so I wanted to build one myself.

I started with [this tutorial](https://medium.com/programmers-blockchain/create-simple-blockchain-java-tutorial-from-scratch-6eeed3cb03fa) by Kass and then changed and added some things on my own.

## How to run it

```
git clone https://github.com/PeterSchweitzer5/simple-blockchain.git
cd simple-blockchain
```

Then open the project in IntelliJ and run `Main.java`.
